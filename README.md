# Gestión de Citas – GABO'S Readaptación y Movimiento

**Materia:** Interacción Humano-Computador (HCI)
**Actividad:** Diseño HCI de un mecanismo para la gestión de citas — Caso GABO'S
**Tipo de entrega:** Evidencia de trabajo grupal en GitHub (2 puntos)

## Descripción del proyecto

GABO'S Readaptación y Movimiento es un centro de fisioterapia que gestiona sus citas de forma manual, mediante WhatsApp y una agenda física, lo que genera pérdida de información, reprocesos y falta de indicadores. Este repositorio documenta el trabajo colaborativo del equipo para analizar el proceso actual (AS-IS), identificar usuarios y necesidades, comparar mecanismos de agendamiento, definir indicadores de eficiencia, construir metáforas de interfaz y proponer un prototipo navegable con su respectivo protocolo de validación, aplicando principios de usabilidad, accesibilidad y modelos mentales propios de HCI.

## Metodología de trabajo

- Las tareas se repartieron según las 8 actividades de la prueba práctica, agrupadas en 4 frentes de trabajo (uno por integrante).
- Coordinación mediante grupo de WhatsApp con revisiones periódicas del avance.
- El seguimiento del trabajo se gestionó mediante **Issues de GitHub**, uno por actividad principal.
- Antes de fusionar cualquier cambio a la rama principal, otro integrante distinto al autor revisó y comentó el Pull Request correspondiente.
- Se verificó que cada artefacto (flujo AS-IS, usuarios, mecanismos, indicadores, metáforas y prototipo) mantuviera coherencia entre sí, ya que todos describen el mismo proceso de gestión de citas de GABO'S.

## Reflexión grupal 

El desarrollo de este caso nos permitió comprobar que el diseño centrado en el usuario exige coherencia entre todas sus etapas: cada decisión tomada en el análisis AS-IS se reflejó directamente en las necesidades identificadas, en el mecanismo elegido, y este a su vez en las metáforas y el prototipo final. Entendimos que una interfaz atractiva no basta si no resuelve un problema real y medible: los indicadores de eficiencia nos obligaron a justificar cada elección con evidencia, no con preferencia personal. Este ejercicio reforzó que la usabilidad, la accesibilidad y los modelos mentales no son pasos aislados, sino un mismo camino que debe sostenerse desde el primer boceto hasta la validación con usuarios reales.
